# ALX — Backend: User Data

Projects on handling user data safely — authentication, session management and protecting personally identifiable information — from the ALX Software Engineering program.

## Projects

- **0x00-personal_data** — logging with PII redaction, password hashing (bcrypt), encrypted DB connections
- **0x01-Basic_authentication** — implementing HTTP Basic Auth from scratch
- **0x02-Session_authentication** — session-based auth, cookies and expiry
- **0x03-user_authentication_service** — a full auth service with Flask and SQLAlchemy

## Tech

Python · Flask · SQLAlchemy · bcrypt · authentication · data privacy
